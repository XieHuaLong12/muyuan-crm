# WhatsApp Web 本地同步助手

## 使用范围

Chrome/Edge 扩展只在用户点击时读取当前 WhatsApp Web 页面已经挂载在 DOM 中的消息。“同步已加载聊天”会遍历**已打开的 WhatsApp Web 标签页**，每个标签页只处理当前显示的聊天，不会点击侧栏联系人、自动滚动或翻页。网页未加载的旧消息不会导入。WhatsApp 更改页面结构时，采集器需要重新验证和调整。

导入只记录文本和附件元数据（种类、可见文件名等）；不上传附件本体或媒体链接。没有稳定网页消息 ID、可确认时间的消息会跳过；没有可确认国际号码的消息进入待认领队列。群聊暂不支持。浏览器扩展无法可靠读取当前登录账号的本人号码，因此操作前须由用户填写并核实，CRM 授权码也绑定这个号码。

## 部署

1. 先备份 MySQL。部署包含 `prisma/migrations/20260928110000_whatsapp_web_sync` 的代码。确认原有 `DATABASE_URL`、`AUTH_SECRET` 环境变量按现有部署配置可用；若沿用当前 `build/start` 脚本，还需原有 `SEED_ADMIN_PASSWORD`。本功能无需新增服务端环境变量，也不接收 WhatsApp 密码、Cookie 或登录凭据。
2. 在 CRM 项目目录运行 `npx prisma migrate deploy`、`npx prisma generate`，然后按现有流程构建并重启 CRM。注意项目现有 `npm run build` 和 `npm start` 会执行 `scripts/production-init.mjs`，它也会迁移数据库并更新种子管理员；生产发布前核对该脚本的现有配置。建议先在独立测试库验收迁移。
3. 用 HTTPS 打开 CRM 的“沟通中心 → 本地同步助手”，创建一个绑定本人 WhatsApp 国际号码的 30 天授权。授权码只显示一次；CRM 数据库仅保存 SHA-256 摘要。销售人员只能访问自己的客户、授权、日志与待认领记录。
4. 在 Chrome/Edge 打开扩展管理页，开启开发者模式，选择“加载已解压的扩展程序”，指向 `extensions/whatsapp-local-sync`。扩展不需要打包或构建。
5. 打开 WhatsApp Web 并登录自己的账号。在扩展里填写 CRM 的 HTTPS 地址、刚创建的授权码、本人 WhatsApp 国际号码、聊天记录的日期顺序（日/月/年或月/日/年），然后保存。扩展向指定 CRM 域名请求访问权限。授权码只存于 `chrome.storage.session`，浏览器会话结束后需重新输入。
6. 先点击“预览匹配结果”，核对号码和数量；再使用“同步当前聊天”或“同步已加载聊天”。在 CRM 管理页查看成功/跳过/失败数量，并手动认领未匹配记录。

本机开发允许 CRM 地址为 `http://localhost` 或 `http://127.0.0.1`；远程 CRM 必须使用 HTTPS。更换 WhatsApp 登录账号后，撤销旧授权并创建与新账号号码绑定的授权。

## 数据规则

- E.164 号码必须是 `+` 加国家码和号码，允许输入前缀 `00`。CRM 历史 `waId` / `whatsappNormalized` 的纯国际数字会在比较时转换；`phone` / `whatsapp` 的裸号码若无法确认国家码会进入待认领，不凭姓名自动合并。
- `phone`、`whatsapp`、`whatsappNormalized`、`waId` 任一字段精确命中一个有权限客户时自动入库。多个客户同号进入待认领队列。
- `WhatsAppMessage.source` 区分 `whatsapp_web`、`cloud_api`、`gupshup`；旧记录标为 `legacy`，避免误称其来自官方 API。`sourceKey` 使用来源、授权账号、会话和网页消息 ID 计算，队列表唯一索引保障重复批次和并发不会生成重复记录。网页和 Cloud API 的不同 ID 不做猜测式跨来源去重。
- 导入历史消息不会更新 `Customer.lastInboundAt` / `lastOutboundAt`，也不会触发 Cloud API 的 24 小时发送窗口、AI 或工作流。只在客户聊天记录中显示原始消息时间。
- 手动认领需再次检查当前用户对客户的访问权限，并在一个事务中标记队列与创建消息。取消或过期设备授权不会删除已同步记录。

## 验收清单

- [ ] 在独立测试库应用迁移，再运行 CRM 页面和 API 冒烟测试。
- [ ] 用带国家码的号码预览：唯一匹配、无匹配、重复客户同号三种情况。
- [ ] 销售账号无法看到/认领其他销售的客户；管理员可按权限选择客户，但设备与队列仍按用户隔离。
- [ ] 同一聊天同步两次，第二次全部跳过；两个扩展窗口同时同步不重复入库。
- [ ] 手动认领后，消息出现在正确客户聊天窗口；重复认领不重复创建。
- [ ] 检查 inbound/outbound、时间、来源、附件元数据和原网页消息 ID；附件无下载文件时显示“仅保存元数据”。
- [ ] 用没有稳定 ID、无法解析时间、群聊、无国际号码、`@lid` 会话检查跳过或待认领行为。
- [ ] 检查本地历史导入不会改变 Cloud API 可发送窗口。
- [ ] 撤销/到期的授权无法再预览或同步；错误日志不含聊天正文、密码、Cookie 或授权码。
- [ ] 在实际 Chrome/Edge 与当前 WhatsApp Web 版本手工验证 DOM 采集；自动化 fixture 测试不能替代此项。
