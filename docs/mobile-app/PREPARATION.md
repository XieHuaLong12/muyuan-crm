# LVANJU BOS App 开发准备清单

> 适用于已确认的方案：先做 HarmonyOS 7 版、Android 随后、企业内部分发、公司配发手机（华为 HarmonyOS 7 + 1 款 Android）、推送统一用华为、App 名称 LVANJUBOS、包名 `online.avenlee.bos`、不做审批、不加收款记录、不做英文界面、允许离线查看最近客户（默认范围）、每位销售接入自己的 WhatsApp 号码（2026-11-11）。
> 技术方案见 [NATIVE_PLAN.md](NATIVE_PLAN.md)。本清单列的是**开工前需要公司准备或决定的东西**，按「谁来办、什么时候要」排列。

## 0. 最先做的三件事

1. **确认那款 Android 手机的具体型号**（§2）。推送定为统一用华为，所以它需要是带华为移动服务（HMS）、能装 Android 应用的华为手机。
2. **注册华为开发者联盟企业账号**（§3）。两个 App 的推送、HarmonyOS 的开发签名与企业内部分发都用这一个账号，企业实名认证需要时间。
3. **找到 Logo 的矢量源文件**（§4）。仓库里只有一张 520×211 的 JPG，做不了 App 图标。

## 2. 手机（公司配发）

| 准备项 | 建议 | 为什么 |
| --- | --- | --- |
| 机型 | **1 款华为 HarmonyOS 7 + 1 款 Android**（已定） | 品牌越少，推送接入、后台保活设置、测试工作量越小 |
| Android 那款 | 选带华为移动服务（HMS）、能安装 Android 应用的华为机型（例如还在用 HarmonyOS 4.x / EMUI 的型号）。如果选其他品牌，推送要改接该品牌的推送，工作量和风险都会增加 | 推送统一用华为的前提 |
| 系统升级 | 用设备管理锁定那款 Android 华为机的系统大版本：一旦升级到 HarmonyOS 5 及以后，它就不能再装 Android 版，要改装 HarmonyOS 版 | 避免员工自行升级后 App 打不开 |
| 屏幕 | 6.1–6.8 英寸，常见分辨率 | 原型按 360–430dp 设计 |
| 设备管理（MDM） | 两款都是华为机，优先评估华为的企业设备管理方案；采购前确认它同时支持 HarmonyOS 7 和那款 Android 华为机 | 统一安装和更新 App；强制锁屏密码；允许 App 自启动、关闭电池优化（推送才稳定）；锁定 Android 那款的系统大版本；**手机丢失或员工离职时远程擦除离线客户数据** |
| WhatsApp | 每位销售在公司手机上登录**自己在 BOS 连接的 WhatsApp 号码**（已定） | 这样从手机 WhatsApp 发出的消息才会同步回 BOS。BOS 目前只能连一个号码，多号码要先改造（§9） |
| 测试机 | 华为 HarmonyOS 7 机型、Android 机型各 2 台（一台保持最新系统、一台保持较旧系统），另加 1 台小屏手机 | 两端开发和测试同时用；推送要在真机上测 |

## 7. 离线查看最近客户：已确认的范围（2026-11-11 采用默认值）

| 项目 | 规则（原型已按此实现） |
| --- | --- |
| 保存范围 | 我负责的、最近 30 天联系过或有待跟进的客户，最多 100 位；管理员同样只保存自己负责或最近看过的客户，不保存全公司 |
| 保存内容 | 客户资料、联系方式、阶段、标签、下次跟进、最近 20 条动态 |
| 不保存 | 订单、报价、经营数据、WhatsApp 完整聊天记录 |
| 离线能做的事 | 查看；打电话；打开 WhatsApp App；写跟进（保存在本机，联网后自动同步） |
| 离线不能做的事 | 改阶段、改回访时间、改标签、分配、新建客户（要查重）、发 BOS 会话消息 |
| 安全 | 本机加密保存；退出登录、账号停用、修改密码、远程擦除时自动清除；设备管理强制锁屏密码 |

## 9. WhatsApp 多号码（BOS 改造，App 依赖）

每位销售在公司手机上用自己的 WhatsApp 号码，BOS 需要能同时连接多个号码。现状与改造思路见 NATIVE_PLAN §2 S14。这是 BOS 的独立项目，可以和 App 开发并行；开始设计前需要你确认：

1. 客户转交给别的销售后，用原号码继续聊，还是换成新负责人的号码（客户会看到号码变了）？
2. 广告「点击 WhatsApp」进来的线索打到哪个号码？是公司一个总号码再分配，还是每个销售各投各的广告？
3. 管理员能否查看所有号码的会话（现在管理员能看全部客户）？
4. 每个号码在服务商那里怎么开通、怎么计费（现有发送走 Gupshup，号码连接用 Meta 共存模式）？

在多号码上线之前，App 仍按现在的单号码工作；会话页已预留「从哪个号码发送」的显示。
