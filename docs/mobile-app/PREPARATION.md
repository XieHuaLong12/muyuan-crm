# LVANJU BOS App 开发准备清单

> 适用于已确认的方案：Android 与 HarmonyOS 同时开发、企业内部分发、公司配发手机、不做审批、不加收款记录、不做英文界面、允许离线查看最近客户（2026-11-11）。
> 技术方案见 [NATIVE_PLAN.md](NATIVE_PLAN.md)。本清单列的是**开工前需要公司准备或决定的东西**，按「谁来办、什么时候要」排列。

## 0. 最先做的三件事

1. **定手机型号**（§2）。机型定了，推送只需要核实这几个品牌，测试机也只买这几款。
2. **注册华为开发者联盟企业账号**（§3）。HarmonyOS 开发、签名、推送、企业内部分发都要用它，企业实名认证需要时间。
3. **找到 Logo 的矢量源文件**（§4）。仓库里只有一张 520×211 的 JPG，做不了 App 图标。

## 2. 手机（公司配发）

| 准备项 | 建议 | 为什么 |
| --- | --- | --- |
| 机型 | **只选 2 款**：1 款出厂即 HarmonyOS 5 或 6 的华为手机 + 1 款 Android 手机 | 品牌越少，推送接入、后台保活设置、测试工作量越小 |
| 华为机的系统版本 | 选出厂就是 HarmonyOS 5/6 的型号 | 旧的 HarmonyOS 4 / EMUI 华为机跑的是 Android App，等于多了一个品牌要适配 |
| 屏幕 | 6.1–6.8 英寸，常见分辨率 | 原型按 360–430dp 设计 |
| 设备管理（MDM） | 采购前确认该品牌支持的企业设备管理方案（华为企业设备管理、所选 Android 品牌的企业方案，或支持这两个品牌的第三方 MDM） | 统一安装和更新 App；强制锁屏密码；允许 App 自启动、关闭电池优化（推送才稳定）；**手机丢失或员工离职时远程擦除离线客户数据** |
| WhatsApp | 确认销售在公司手机上登录的是哪个号（公司 WhatsApp Business 号还是个人号） | App 里「打开 WhatsApp App」发出的消息，只有在 BOS 已连接的号码上才会同步回 BOS 会话 |
| 测试机 | 每个选定型号 2 台（一台保持最新系统、一台保持较旧系统），另加 1 台小屏手机 | 两端开发和测试同时用；推送要在真机上测 |

## 3. 账号、证书与资质（公司办理）

| 准备项 | 用途 | 什么时候要 |
| --- | --- | --- |
| 华为开发者联盟**企业账号**（企业实名认证，准备营业执照等企业资料） | HarmonyOS 开发与签名；Push Kit；企业内部分发；华为 Android 机的推送 | 开工前（M0） |
| AppGallery Connect 项目：创建 HarmonyOS 应用、开通 Push Kit、申请推送**消息分类权益**（工作提醒类） | 没有分类权益的推送会被当作营销消息：静音、限量 | M0 申请，M2 前到位 |
| HarmonyOS **企业内部分发资格**与对应的证书、Profile | 公司手机安装 HarmonyOS 版 App | M0 申请；正式资格下来之前先用测试分发给少数人试装 |
| 所选 Android 品牌的**推送开放平台企业账号** | App 被关掉后仍能收到新询盘、首联超时提醒 | M0；同时核实未上架应用能否接入 |
| **Android 签名密钥** | 所有 Android 安装包都用它签名，之后的版本必须用同一把才能覆盖安装 | M0 生成；指定 1 名保管人，离线备份 2 份，不放进代码仓库和个人电脑 |
| **App 名称** | 已定为 **LVANJUBOS**：手机桌面、通知、安装与更新提示、「关于」页都显示这个名字。拿到测试机后在桌面上看一眼是否显示完整（9 个大写字母较宽，个别桌面可能显示省略号） | ✅ |
| **包名** | 建议用公司域名倒过来再加 `.bos`（例如域名是 `example.com`，包名就是 `com.example.bos`），两端一致；**发布后不能再改**。告诉我公司域名即可确定 | M0 |
| App 备案 | 工信部要求 App 备案，主要在应用市场上架时核验；内部分发是否需要，请与法务或华为企业分发确认 | M0 确认 |
| 员工告知文件 | 隐私与权限说明（App 收集哪些数据、为什么要通知权限、离线保存哪些客户数据）；公司手机使用规定（锁屏密码、丢失上报、离职交还） | 内部推广前（M5） |

## 4. 品牌与设计素材

| 准备项 | 要求 |
| --- | --- |
| Logo 矢量源文件 | AI / SVG / PDF 任一种。仓库只有 `public/brand/lvanju-logo.jpg`（520×211），放大会模糊 |
| App 图标定稿 | Android 自适应图标、HarmonyOS 分层图标都要「前景 + 背景」两层，1024×1024 起。建议用 Logo 里的房屋窗格标志 + 品牌绿底，字标放在启动页 |
| 启动页 | 品牌绿底 + 白色字标，0.5 秒内进入 App，不放广告 |
| 原型定稿 | 当前原型是界面基准；评审后把要改的地方一次提出，开发期间再改的成本会翻倍 |
| 字体 | 两端都用手机系统自带的字体（HarmonyOS Sans、各品牌 Android 的系统字体），**不需要购买字体授权** |

## 5. 服务器与开发环境（开发团队准备，公司授权）

| 准备项 | 说明 |
| --- | --- |
| 测试环境 | 与生产隔离的 BOS 测试站 + 生产数据库副本（项目规范禁止在生产库跑验收脚本）。手机连测试站开发和测试 |
| 测试账号 | 管理员 2 个、销售 3 个，测试站上建 |
| 正式域名与 HTTPS | 沿用现有 BOS 域名（`PUBLIC_APP_URL`），App 只连 HTTPS |
| 安装包存放 | 服务器上代码仓库以外的目录（与现有 `MEDIA_STORAGE_DIR` 同类做法）或对象存储；下载页需要登录 BOS 账号 |
| 推送凭据 | 各推送平台的应用 ID、密钥配置成服务器环境变量（Hostinger 面板），不进代码仓库 |
| 开发电脑 | Android：Android Studio。HarmonyOS：DevEco Studio（Windows 或 macOS）。两套工具都比较吃内存，建议 32GB 内存 |
| 打包与签名 | 打包流程放到 CI，签名密钥存 CI 的机密配置里，由保管人录入 |
| 崩溃与日志收集 | 选一个国内可用、两端都支持的服务，接入前确认数据存放位置 |

两端开发要每天同步接口和命名（路由、通知渠道、错误提示），每周用原型做一次两端并排走查。

## 7. 离线查看最近客户：已确认的范围（2026-11-11 采用默认值）

| 项目 | 规则（原型已按此实现） |
| --- | --- |
| 保存范围 | 我负责的、最近 30 天联系过或有待跟进的客户，最多 100 位；管理员同样只保存自己负责或最近看过的客户，不保存全公司 |
| 保存内容 | 客户资料、联系方式、阶段、标签、下次跟进、最近 20 条动态 |
| 不保存 | 订单、报价、经营数据、WhatsApp 完整聊天记录 |
| 离线能做的事 | 查看；打电话；打开 WhatsApp App；写跟进（保存在本机，联网后自动同步） |
| 离线不能做的事 | 改阶段、改回访时间、改标签、分配、新建客户（要查重）、发 BOS 会话消息 |
| 安全 | 本机加密保存；退出登录、账号停用、修改密码、远程擦除时自动清除；设备管理强制锁屏密码 |
