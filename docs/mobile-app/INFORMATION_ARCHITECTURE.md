# LVANJU BOS 移动端 · 第二步（上）：信息架构、页面清单与操作流程

> 原则：手机只放**高频、需要随时处理**的工作（联系客户、跟进、看数、处理提醒）；低频、需要大屏的工作（批量导入、产品库维护、逐行报价、运费库、广告分析、系统集成）留在电脑端，App 内给出「在电脑端完成」的明确提示，而不是缩小 PC 页面。

## 1. 导航结构

```
底部导航（5 个，固定）
├── 工作台   今日概览 → 任务 / 经营数据 / 报价 / 待付款订单（快捷入口）
├── 客户     队列 + 搜索 + 筛选 → 客户详情 → 跟进 / 回访 / 阶段 / 联系
├── 订单     订单 | 报价单 → 订单详情 / 报价单详情
├── 消息     通知（分类、未读、批量）| WhatsApp 会话 → 会话
└── 我的     资料、业绩摘要、通知设置、账号安全、离线数据、外观、关于（检查更新）、退出
```

- **每个底部页签有独立的返回栈**（Android Navigation Compose 每个 tab 一个 back stack；HarmonyOS `Tabs` + 每个 tab 一个 `Navigation`/`NavPathStack`），切换页签不丢失位置。
- 进入详情页时**隐藏底部导航**，详情页底部换成该页的主操作条（写跟进、联系客户、推进状态）。
- 再次点击当前页签：已在根页时回到顶部，否则回到该页签根页。
- 系统返回（手势 / 返回键）：关闭对话框 → 关闭底部弹层 → 返回上一页 → 非工作台页签的根页回到工作台 → 工作台根页「再按一次退出」。
- 和现有 PWA 的区别：PWA 第 5 个入口是「更多」，把十几个分区塞进弹层；App 按任务重新归类，任务、经营数据从工作台进入，产品库 / 运费库 / 广告分析 / 团队管理 / 系统设置不进入 App 第一阶段。

### 「消息」的定义

现有 BOS 的「消息」指 WhatsApp 会话。需求中的「消息」是通知中心。App 中「消息」页签分两段：**通知**（系统事件）与 **WhatsApp 会话**（客户聊天）。页签角标 = 未读通知 + 未读会话。

## 3. 关键操作流程（点击次数）

| 场景 | 路径 | 点击 |
| --- | --- | --- |
| 新线索 5 分钟内首联（销售） | 系统通知「新分配客户」→ 客户详情 → WhatsApp → 在 BOS 会话中回复 | 3 |
| 同上，从工作台 | 首联倒计时卡片「WhatsApp」→ 在 BOS 会话中回复 | 2 |
| 回复等待中的客户 | 工作台「客户在等你回复」→ 会话 → 发送 | 2 + 输入 |
| 写跟进并设下次时间 | 客户详情「写跟进」→ 选快捷短语 / 输入 → 选「明天 10:00」→ 保存 | 3 + 输入 |
| 打完电话补记录 | 联系 → 拨打 → 回到 App 自动询问「记录这次通话？」→ 记录 → 保存 | 4 + 输入 |
| 改阶段 | 客户详情阶段标签 → 选阶段（结束类阶段弹出原因） | 2 |
| 分配 A 级线索（管理员） | 置顶提醒「去分配」→「分配给销售」→ 选人 → 确认 | 4 |
| 完成今日任务 | 工作台「我的待办」勾选（可撤销） | 1 |
| 查看物流异常 | 工作台「重要提醒」→ 订单详情 | 1 |
| 老板看今日经营 | 打开 App：今日业绩、本月进度、四个关键数、趋势 **无需点击** | 0 |
| 批量标记通知已读 | 消息 → 全部已读（可撤销）/ 选择 → 勾选 → 标为已读 | 1 / 3+ |

## 4. 页面状态

每个数据区块都有四种状态（原型控制台可切换验证）：

| 状态 | 表现 |
| --- | --- |
| 加载中 | 与内容同形的骨架屏，不用转圈占满屏幕 |
| 空 | 图标 + 一句话说明为什么空 + 下一步按钮（如「新建客户」） |
| 出错 | 说明发生了什么（网络不稳定、数据没有更新）+「重新加载」；已填写的表单内容不丢 |
| 正常 | 顶部显示「数据截至 HH:mm」，支持下拉刷新 |
| 离线 | 顶栏下方显示「离线 · 显示 HH:mm 保存在本机的数据」；客户列表与详情只显示本机保存的最近客户，可写跟进（联网后自动同步）；其余页面显示「这页需要联网」并提供「查看离线客户」；需要联网的按钮点击后提示原因 |

危险操作（取消订单、移入回收站、退出登录、退出其他设备、放弃未保存的表单）一律二次确认，需要原因的操作在确认框内直接填写。可逆操作（完成任务、改阶段、标记已读、写跟进）不打断，用带「撤销」的提示代替确认。

## 5. 通知分类与跳转

| 分类 | 通知（现有 kind / 新增） | 点击跳转 | 默认提醒 |
| --- | --- | --- | --- |
| 询盘 | 待分配新线索 `POOL_LEAD`、新线索已分配 `NEW_LEAD`、新分配客户 `ASSIGNED`、再次留资 `REPEAT_SUBMISSION` | 客户详情 / 待分配列表 | A/B 持续响铃，C 响一次，D 静默（沿用 `ringFor`） |
| 跟进 | 任务即将到期 `TASK_DUE`、任务到期 `TASK_OVERDUE`、首联超时 `FIRST_CONTACT_OVERDUE` | 任务详情 / 客户详情 | 响铃 + 振动 |
| 订单 | 新订单、定金 / 尾款到账（**新增**） | 订单详情 | 响铃 + 振动 |
| 异常 | 物流超预计到货（订单提醒已有计算，**新增推送**）、线索需人工处理 `LEAD_NEEDS_HUMAN`、A/B 首联超时 | 订单 / 客户 / 线索接入 | 响铃 + 振动 |
| 公告 | 今日简报（已有 08:00 推送）、系统公告（**新增**） | 经营数据 / 公告详情 | 静默 |

优先级显示：紧急（红）、重要（橙），普通不加标签；未读加粗 + 红点。
