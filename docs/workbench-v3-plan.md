# Sales Workspace V3

目标：让销售先看到要处理的人和事，再在一个固定空间内完成沟通、报价和跟进。

- 导航：Today、客户、WhatsApp、任务中心；漏斗、数据、目标和设置沿用原有业务。
- Today：真实待回复/未读、今日任务、逾期和提醒；优先客户按采购意向、消息、金额和超时排序，不跨币种汇总金额。
- 客户：35% 可搜索客户列表 + 65% 工作区；选中客户仅更换右侧数据，详情/跟进/报价/订单/任务在页内切换。
- 聊天：局部 5 秒同步、白/浅绿气泡；AI 草稿位于右侧。快捷回复先进入编辑框，发送必须由用户操作。
- 任务：独立持久化 TODO/DOING/DONE，可勾选、撤销、改期、优先级、删除；提前提醒与逾期均有文字信息。
- 自动流程：未回复 24 小时、报价 3 天未回复；样品寄出和生产开始由明确业务事件触发；DeepSeek 给出可执行下一步后生成去重任务。
- 提醒：数据库保存 reminder 时间；所有页面的通知中心定期读取，到点显示，无需新增定时服务。关闭网页期间不发系统推送，下次打开呈现已到期提醒。
- 性能：新页面由 Server Component 载入首屏，交互区域为 Client Component；任务完成乐观更新并支持失败回滚，聊天不会刷新整页；尊重 prefers-reduced-motion。
- 视觉：#F7F8F6 背景，#173E35 深绿，Inter/系统字体，16px 圆角；少量状态颜色，细线条图标，轻阴影，短反馈动画。
