# 手机 App（PWA）

CRM 可以安装到手机桌面：有自己的图标，点开全屏运行，没有浏览器地址栏，用起来和 App 一样。它和电脑版是同一个网站、同一个账号和数据，不需要应用商店，也不需要单独发版——网站更新后，手机上下次打开就是新版本。

## 怎么安装

前提：用正式域名的 **HTTPS** 地址打开（`http://` 或局域网 IP 不能安装）。

| 手机 | 步骤 |
| --- | --- |
| 安卓（Chrome / Edge / 三星浏览器） | 登录后点底部「更多」，在「把 CRM 装到手机桌面」一栏点「安装」。没有出现时：浏览器右上角菜单 →「安装应用」或「添加到主屏幕」 |
| 安卓（华为 / 小米 / OPPO / vivo 自带浏览器） | 浏览器菜单 →「添加到桌面」或「添加至主屏幕」。如果只能生成普通书签，改用 Chrome 或 Edge 安装 |
| iPhone / iPad | 用 Safari 打开 → 点「分享」按钮（新版 iOS 在「···」菜单里）→「添加到主屏幕」。底部「更多」里也写了这一步 |
| 微信里打开的链接 | 微信内无法安装：点右上角「···」→「在浏览器打开」，再按上面的步骤安装 |

手机上安装入口固定在底部「更多」里，不占页面位置；平板等较宽的触屏仍在页面顶部显示提示条，可以点「×」关掉，之后不再出现。已经从桌面图标打开时两处都不显示。电脑上不显示（Chrome / Edge 地址栏右侧仍可安装成桌面应用）。

**iPhone 注意**：从桌面图标打开的 App 和 Safari 不共享登录状态，第一次打开需要重新登录一次。

长按 App 图标（安卓）可以直接进入「今日跟进」「客户」「待办」。

## 手机上的布局

屏幕宽度不超过 760px 时（2026-11-10 起）：

- **底部导航**：左侧菜单换成固定在屏幕底部的 5 个入口。管理员是「今日（工作台）· 消息 · 客户 · 数据（经营总览）· 更多」，销售是「今日 · 消息 · 客户 · 报价 · 更多」。其余分区、安装入口、修改密码和退出登录都在「更多」里。入口的划分在 `lib/role-workspace.ts` 的 `phoneNavigation`，分区和标签仍是电脑版那一套。
- **顶栏**：一行、固定在顶部：搜索框、待分配 / 待首联 / 今日待办的数量、通知开关。等待时长等细节在点进去的页面看。
- **标签**：同一分区的页面标签排成一行，左右滑动，当前页自动滑到可见位置。
- **控件尺寸**：输入框文字 16px（小于 16px 时 iPhone 点输入框会自动放大页面），按钮和输入框高 44px，页面内的切换开关高 40px。
- **消息页**：会话列表占满顶栏和底部导航之间的空间；点进一个会话后底部导航让开，输入框贴到屏幕底部，点左上角箭头回到列表。
- `viewport-fit=cover`：底部导航延伸到屏幕边缘，并按 iPhone 底部横条的安全区留白。

电脑和平板（宽于 760px）的布局不变。表格和看板在手机上仍需横向滑动。

## 提醒通知

在 App 顶部点「开启通知」（手机上是顶栏右侧的铃铛按钮）并允许后，这台手机就登记到服务器。之后**App 关着也能收到**新线索和新分配的系统通知（Web Push），点通知直接打开对应的客户。

- 安卓：Chrome / Edge 中安装的 App 支持。A、B 级线索的通知会一直留在通知栏直到点开，并长振动。
- iPhone：需要 iOS 16.4 及以上，并且必须是从桌面图标打开的 App（Safari 网页里没有通知权限）。iPhone 不允许网页 App 常驻通知或自定义铃声，通知按系统设置响一次。
- 谁收到：每一条新表单都推给所有管理员（D 级和 24 小时前的旧留资不推）；线索分配给谁，就推给谁的手机；老客户再次留资推给负责人。
- 其他推送（2026-10-14 起）：每天 08:00 起把「今日简报」推给管理员；A/B 级线索首联超时推给负责人和管理员；当天线索明显偏少时推给管理员。详见 [管理与销售工作空间](ROLE_WORKSPACES.md#老板助理)。
- App 开着时：A、B 级（以及还没评完级的）新线索在页面顶部置顶并持续响铃，直到有人点「去处理」、关掉，或别人已经分配了它；C 级弹一次并响一声；D 级不打扰。
- 退出登录时这台手机不再接收这个账号的提醒；换人登录会自动改为新账号。
- 推送服务地址只接受 Google、Apple、Mozilla、Microsoft 的官方推送服务。

## 没有网络时

客户数据始终从服务器读取，手机上不缓存任何客户、订单或报价数据（数据私密、也必须是最新的）。断网时打开页面会显示「网络未连接」，联网后自动重新打开。

## 实现

| 文件 | 作用 |
| --- | --- |
| `app/manifest.ts` | 应用名称、图标、全屏显示、主题色和长按快捷方式（`/manifest.webmanifest`） |
| `app/icon.png`、`app/apple-icon.png`、`public/icons/` | 浏览器标签图标、iPhone 桌面图标、安卓图标（含可裁剪的 maskable 图标），由 `public/brand/lvanju-logo.jpg` 生成 |
| `public/sw.js` | Service Worker：断网时返回离线页；收到服务器推送时显示通知（`push`），点击通知打开对应页面。**不缓存页面和接口数据** |
| `services/push-service.ts`、`app/api/push`、`components/push-notifications.ts` | Web Push：设备登记 / 注销、VAPID 密钥（未配置环境变量时自动生成并加密保存）、发送与失效设备清理 |
| `services/lead-alert-service.ts`、`LeadAlert` 表 | 线索提醒发件箱：与建客户 / 分配同一事务写入，响应返回后先评级再推送；定时任务和页面同步兜底补发 |
| `services/boss-brief-service.ts` | 今日简报和异常提醒（首联超时、线索偏少）的推送 |
| `public/offline.html` | 离线页 |
| `components/pwa.tsx` | 生产环境注册 Service Worker；安装入口：手机在底部「更多」里，较宽的触屏在 `BOSShell` 页面顶部 |
| `components/ui/MobileNav.tsx`、`app/mobile-shell.css` | 手机布局：底部导航、「更多」弹层、固定顶栏和手指尺寸的控件（见上文「手机上的布局」） |
| `components/live-notifications.tsx` | 系统通知优先通过 Service Worker 显示（手机只支持这种方式），没有时退回网页通知 |
| `next.config.ts` | `/sw.js` 返回 `Cache-Control: no-cache`，保证手机能及时拿到新版本 |

更新 `public/sw.js` 后，手机下次打开会自动换成新版本；如果改了离线页内容，把 `sw.js` 里的 `CACHE` 版本号加一。

## 想上架应用商店 / 要 APK 安装包

部署到正式 HTTPS 域名后，可以把网址填进 [PWABuilder](https://www.pwabuilder.com/) 生成安卓 APK / AAB（Trusted Web Activity），或打包提交 Google Play、Microsoft Store。安装包里打开的仍是这个网站，数据和功能与网页版一致；按 PWABuilder 的说明把生成的 `assetlinks.json` 放到 `public/.well-known/` 后，打开时不会显示浏览器地址栏。
