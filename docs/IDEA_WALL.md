# 想法墙 · 每日一签

设计稿：画布 ㉘「想法墙 v2」、㉚「每日一签 · 占卜版」。

## 想法墙（`/ideas`，`lib/idea-wall.ts`、`services/idea-wall-service.ts`）

- **谁能看**：每个人一面自己的墙（`WallNote.userId`），只有自己看得到；管理员在「工作台」、销售在「今日工作」里都有「想法墙」标签。
- **三种纸条**
  - 💡 **想法**（IDEA）：有进度 刚想到 → 想做 → 在做 → 做完了，点纸条上的状态往下走一步。五种纸色可选。
  - ❝ **喜欢的话**（QUOTE）：宋体大字，带出处；写成「……」—— 某某 时自动拆出出处。
  - 📌 **有用的**（USEFUL）：技巧、链接、截图、从别的页面选中的一段字。
- **自动判断**（`guessKind`）：有链接或写着「截图」→ 有用的；带引号、带「——」，或一句以。！结尾的短话 → 喜欢的话；其他 → 想法。猜错了点一下换。`#标签` 写在字里也算。
- **截图**：粘贴、拖进来或点图片按钮，PNG / JPG / WebP / GIF，5 MB 以内，存在媒体目录 `wall/` 下，只有本人能打开（`/api/ideas/[id]/image`）。
- **转成任务**：明天 10:00（公司时区）的一条任务，描述「来自想法墙」；想法变成「在做」，任务做完后想法自动变成「做完了」。
- **提醒**：选一天，到那天在想法墙「今天到日子的纸条」和每日一签那一块里提醒。
- **送到该去的地方**：有用的一句话「存成常用回复」（存成我的、中文、分类「其他」，其他语言在常用回复里补）；截图「放进产品资料」（管理员）。
- **收起来**：存档不删除，「收起来的」里可以放回墙上。
- **帮你理一理**（规则，不用 AI）：两张想法字面相似度（字符二元组的 Dice 系数）≥ 0.45 → 建议合并，留下已经在动或更早的那张；「刚想到」30 天没动 → 挪到想做或收起来；像回客户的话的「有用的」→ 存成常用回复。只给建议，点了才动。
- **今日一句**：当天求过签就是签上的赠言，否则从自己的「喜欢的话」里按日期挑一句。
- **随手贴**：每个页面右下角的 💡（快捷键 N）。先选中页面上的字再打开，选中的字会带进来，默认贴成「有用的」；会记下在哪个页面贴的（例如「经营总览 · 国家作战卡 · 法国」）。

## 每日一签（工作日历「今天」最上面，`lib/daily-sign.ts`、`services/daily-sign-service.ts`）

- **每人每天一签**（`DailySign @@unique([userId, day])`，日期按公司时区）。先选想问的事：成交 / 客户 / 广告 / 灵感 / 心情，再转把手。同一天再求，拿到的还是早上那一签。
- **只有吉签**：大吉 / 中吉 / 吉。签诗是原创的七言四句，每个问题三支签，按人、日期、问题固定挑一支。
- **签上写什么**（求签时整份存下，当天不会变）：
  - 解签：问成交、客户时加上「贵人在某方」——主要市场（近 8 周有效客户最多的国家）相对中国的方向。
  - 运势：综合、成交、客户、广告、灵感五项，3–5 星，问的那一项 4–5 星。
  - 幸运色、幸运数字、吉时（主要市场近 12 周首条回复率最高的 3 小时，没有就 10:00–12:00）、贵人方位。
  - 宜 / 忌：从当天数据来——报价发出 3 天没回的客户、昨晚下班后进线的 A / B、待确认的广告建议、比平均贵 30% 以上的素材、想法墙上放了 14 天以上的想法。数据没说法时用通用的话。
  - 今日赠言：自己想法墙上的「喜欢的话」，没有时用三句古语（荀子《劝学》、《道德经》、《战国策》）。
- **收下**：缩成今天页顶上的一条。
- **对签**：下班前半小时起（默认 21:30），用当天数据看灵不灵——成交：今天的订单和跟进报价客户的回复；客户：今天进线的 A / B 联系了几位、回了几位；广告：今天带来的 A / B 和已回话的；灵感：今天贴了几张、挪了几张；心情：今天在 BOS 里发了几条、回了几位。点 👍 灵 / 😅 不太灵。
- **签册**：本周一到周日每天的签和灵不灵；连续求签天数（今天没求时算到昨天）、本月应验次数；三签以上有一句「周签」小结。
